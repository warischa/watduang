- **เล็งช่องว่างที่หน้า 1 ไม่มีเครื่องมือเล่นได้** (`เกมลงโทษ`, `สุ่มคนโดน`) ไม่เล็ง `เกมสันทนาการ`/`เกมเข้าค่าย` ซึ่ง #03 วัดได้ ≈ 0
- **ทุกเกมต้องใช้ roster ร่วมกับเครื่องมือได้** — นั่นคือจุดต่างแกนกลาง เกมที่ใช้ roster ไม่ได้ ต้องมีเหตุผลพิเศษถึงจะเข้า v1
- เครื่องมือ 4 ตัวที่ตัดสินแล้ว: วงล้อสุ่ม · สุ่มชื่อ/จับฉลาก · สุ่มแบ่งทีม · สุ่มเลข

_(เดิมติด #03 — #03 ปิดแล้วแต่ผลของมันเปิดคำถามใหญ่กว่าคือ #10 ว่าเว็บนี้เป็นเว็บเครื่องมือหรือเว็บเกม ต้องรู้ก่อนถึงเลือกเกมได้ · #03 ยังเพิ่มข้อบังคับด้วยว่า `สุ่มเลข` ต้องถูกพิจารณา — มันใหญ่กว่า `สุ่มชื่อ` และไม่เคยอยู่ในแผน)_

## Question

เกมไหนบ้างเข้า v1 และเกมไหนรอ

เกณฑ์ที่ต้องผ่านพร้อมกัน:
- เล่นได้ 2-10 คน บนเครื่องเดียว
- อธิบายกติกาจบใน 1 หน้าจอ ไม่ต้องมีคนอ่านคู่มือ
- ทำงานได้โดยไม่ต้องมีบทลงโทษเป็นแอลกอฮอล์ (บทลงโทษเป็นกลาง)
- มีคีย์เวิร์ดไทยที่คนค้นจริงรองรับ (จาก #03)
- แบ่งน้ำหนัก **วัดดวง : ปาร์ตี้/สันทนาการ ประมาณครึ่งๆ**

ต้องตอบด้วยว่า:
- แต่ละเกมกินคลังเนื้อหาเท่าไหร่ (เกมที่ต้องมีคำถาม 300 ข้อ แพงกว่าเกมที่ใช้แค่ RNG มาก) — นี่คือต้นทุนที่ซ่อนอยู่และมักถูกประเมินต่ำ
- เกมไหนเป็น "หัวหอก SEO" เกมไหนเป็น "เกมประกอบ"
- เกมไหนแชร์ UI shell เดียวกันได้บ้าง

## Answer — 7 เกมใน v1

| # | เกม | หมวด | เนื้อหาที่ต้องเขียน | roster | `ads` |
|---|---|---|---|---|---|
| 1 | **ระเบิดเวลา** | ปาร์ตี้ | 0 | ✅ | true |
| 2 | **สุ่มคนโดน** *(= หน้า "ใครแพ้หมดแก้ว")* | ปาร์ตี้ | 0 | ✅ | **false** |
| 3 | **จับไม้สั้น** | ปาร์ตี้ | 0 | ✅ | true |
| 4 | **ใครในวงนี้น่าจะ…** | ปาร์ตี้ | ~100 ประโยค | ✅ | true |
| 5 | **ความจริงหรือท้า** | ปาร์ตี้ | ~80 ข้อ (คลังเล็กก่อน) | ✅ | true |
| 6 | **วัดดวงวันนี้** | วัดดวง | ~50 คำทำนาย | ⚠️ ใช้ชื่อ ไม่พึ่ง | true |
| 7 | **ดวงความรัก / คู่ไหนเข้ากัน** | วัดดวง | เบา | ✅ เลือก 2 คน | true |

**สัดส่วน 5 ปาร์ตี้ : 2 วัดดวง** — เอียงจาก "ครึ่งๆ" ที่ตกลงไว้ แต่ยอมรับได้เพราะช่องว่างที่ [#03](03-thai-seo-demand.md) เจออยู่ฝั่งปาร์ตี้ และแบรนด์ "วัดดวง" ถือฝั่งนั้นไว้ด้วยชื่ออยู่แล้ว

### ⚠ ขอบเขตขยาย — บันทึกไว้ ไม่ได้ปรับลดเอง

ตกลงกันตอนต้นว่า **4-6 เกม** ผลลัพธ์คือ **7** · ต้นทุนโค้ดแทบไม่ขึ้น (3 เกมแรกเนื้อหาเป็นศูนย์) แต่ **ต้นทุนเนื้อหาขึ้นจาก ~150 เป็น ~230+ ข้อ** ที่ต้องเขียนและตรวจด้วยมือทุกข้อ

นี่คือส่วนที่จะทำให้ตารางงานพลาด ไม่ใช่โค้ด — ถ้าวันหนึ่งงานเริ่มยืด **ตัดจาก #4 หรือ #5 ก่อน** อย่าตัดเกมเนื้อหา-ศูนย์ เพราะมันฟรีอยู่แล้ว

### 🔴 กฎเหล็กสำหรับคลัง "ท้า" ของเกม #5

[#01](01-adsense-policy.md) ยืนยันว่า **คำท้าที่ชักจูงให้ทำร้ายร่างกายจริง เป็น *policy* ของ Google ไม่ใช่ *restriction*** — ข้อเดียวในโปรเจกต์นี้ที่เสี่ยงถูก**ปิดบัญชี**จริง ไม่ใช่แค่เสียรายได้

ดังนั้นคลังคำท้า:

- **ตรวจด้วยมือทุกข้อ ห้ามปล่อยผ่านจาก AI โดยไม่อ่าน** — ข้อนี้ไม่ใช่คำแนะนำ
- ห้ามคำท้าที่มีการกิน ดื่ม กลั้นหายใจ ความเจ็บ ความสูง ไฟ ของมีคม หรือการออกไปนอกสถานที่
- ห้ามคำท้าที่พาไปสู่การเปิดเผยข้อมูลส่วนตัวของคนที่ไม่ได้อยู่ในวง
- เมื่อสงสัย = ตัดออก คลัง 80 ข้อที่ปลอดภัย ดีกว่า 200 ข้อที่มี 1 ข้อทำให้บัญชีหาย

### หมายเหตุ: #2 กับ #3 เป็นเกมเดียวกันในเชิงกลไก

`สุ่มคนโดน` และ `จับไม้สั้น` ต่างก็คือ "สุ่มเลือกคนแพ้ 1 คนจาก roster" โค้ดแกนเดียวกัน ต่างกันแค่ภาพและคำ

**นี่ไม่ใช่ปัญหา มันคือกำไร** — ได้ 2 URL 2 คีย์เวิร์ด โดยต้นทุนส่วนเพิ่มเกือบศูนย์ แต่ให้รู้ตัวว่ากำลังทำ skin ไม่ใช่เกมใหม่ จะได้ไม่ไปเขียนตรรกะซ้ำสองรอบ

### ลำดับการสร้าง — เริ่มที่ ระเบิดเวลา

**ทำไมมันเป็นตัวแรกที่ถูกต้อง:** มันเป็นเกมเดียวในเจ็ดตัวที่ *ต้องการ* การส่งมือถือวนกันจริงๆ — **ตัวเครื่องคือระเบิด** ไม่ใช่เกมที่บังเอิญเล่นบนมือถือได้ ถ้า shell ส่งมือถือทำงานกับเกมนี้ได้ มันทำงานกับที่เหลือได้หมด และมันเนื้อหาเป็นศูนย์ จึงพิสูจน์ *สถาปัตยกรรม* โดยไม่ติดหล่มเรื่องคลังคำ

```
1. ระเบิดเวลา        ← พิสูจน์ shell + manifest + getStaticPaths + GameLayout ครบชุด
2. สุ่มคนโดน          ← พิสูจน์ ads:false + Auto ads page exclusion (ทดสอบ #09 ของจริง)
3. จับไม้สั้น         ← พิสูจน์ว่า "1 เกมใหม่ = 1 ไฟล์ + 1 บรรทัด" จริงไหม (skin ของ #2)
4. วัดดวงวันนี้       ← พิสูจน์ระบบคลังเนื้อหาแยกจากตรรกะ
5. ดวงความรัก        ← พิสูจน์การเลือกคนจาก roster หลายคน
6. ใครในวงนี้น่าจะ…   ← คลังใหญ่ตัวแรก
7. ความจริงหรือท้า    ← ท้ายสุด เพราะคลังต้องตรวจละเอียดที่สุด
```

**ลำดับนี้เรียงตามสิ่งที่แต่ละเกมพิสูจน์ ไม่ได้เรียงตามความสำคัญ** — ถ้าอะไรจะพังในสถาปัตยกรรม มันจะพังที่ 3 ตัวแรกซึ่งเนื้อหาเป็นศูนย์ ซ่อมถูกที่สุด

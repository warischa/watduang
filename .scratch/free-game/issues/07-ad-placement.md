# 07 — วางโฆษณาตรงไหน โดยไม่พังจังหวะเกม

Type: grilling
Status: resolved
Blocked by: 01, 06

## Question

นี่คือ ticket ที่ตัดสินว่าเว็บนี้หาเงินได้จริงหรือเปล่า และมันขัดกันเองอยู่ในตัว: เกมที่สนุกคือเกมที่ลื่น แต่โฆษณาที่ได้เงินคือโฆษณาที่ขวาง

ต้องตัดสิน:
1. โฆษณาอยู่ตรงไหนได้บ้าง — หน้าแรก, หน้าหมวด, หน้ากติกาก่อนเริ่ม, ระหว่างรอบ, หลังจบเกม
2. **ห้ามอยู่ตรงไหนเด็ดขาด** — ระหว่างส่งมือถือ, ตอนเฉลยผล
3. โฆษณาคั่นระหว่างรอบ (interstitial) คุ้มกับความรำคาญไหม
4. Auto ads ของ Google กับวางเอง อันไหนดีกว่าสำหรับเว็บโครงนี้
5. ต้องปิดหมวดโฆษณาแอลกอฮอล์ใน AdSense ไหม (ขึ้นกับผล #02) — ถ้าโฆษณาเหล้าเด้งขึ้นบนเว็บเกมวงเหล้า มันย้อนกลับมาทำลายจุดยืนที่อุตส่าห์ตั้งไว้
6. เว็บมีกี่ pageview ต่อ 1 วงเล่น — ตัวเลขนี้บอกว่ารายได้เป็นไปได้แค่ไหน ควรประมาณก่อนตัดสินใจอย่างอื่น

ถ้า [#09](09-alcohol-in-metadata.md) จบว่าใช้ชื่อ "ใครแพ้หมดแก้ว" ได้ → **หน้านั้นต้องตั้ง Auto ads "Page exclusion (This page only)" และห้ามวางช่องโฆษณา manual** ไม่งั้น Auto ads จะยัดโฆษณาเข้าไปเองด้วยสคริปต์ระดับเว็บ แล้วหน้านั้นก็จะสร้าง ad request จนเข้า Policy Center

**และนั่นทำให้ต้องคิดเรื่อง ad strategy ใหม่หนึ่งข้อ:** หน้านั้นจะเป็น **หน้าที่ไม่หารายได้เอง แต่มีหน้าที่พาคนเข้าเว็บ** — มันต้องออกแบบให้ผู้เล่นเดินต่อไปหน้าอื่นที่มีโฆษณา (ลิงก์ไปเกมอื่น, "เล่นเกมอื่นต่อ", วงล้อสุ่ม) ไม่ใช่หน้าตัน ถ้าคนเข้ามาแล้วเล่นจบแล้วปิด หน้านั้นคือรายได้ศูนย์เปล่าๆ ไม่ใช่การลงทุน

## Answer — sticky ล่างจอ · วางเอง · ปิดหมวดแอลกอฮอล์ · หน้าจบเสนอ 3 เกม

### สิ่งที่ตัดสินใบนี้จริง ไม่ใช่ตำแหน่งช่องโฆษณา

**1 วงเล่นเกม = 1 pageview** กลุ่มเปิด `/game/timebomb` เล่น 20 รอบ 30 นาที แล้วปิด · AdSense จ่ายต่อ impression ไม่ได้จ่ายต่อนาที **เว็บนี้จึงมี engagement สูงมากแต่ pageview ต่ำมาก ซึ่งเป็นการผสมที่แย่ที่สุดสำหรับโฆษณา**

```
เล่นเกมเดียวจบ              →  1 pageview
เล่นต่อ 3 เกม + 1 เครื่องมือ  →  4 pageview   ← กลุ่มเดิม เวลาเดิม รายได้ 4 เท่า
```

**ปุ่ม "เล่นเกมอื่นต่อ" จึงสร้างรายได้มากกว่าตัวช่องโฆษณาเอง** — และทำให้การที่ #10 ตัดสินให้มี 7 เกม + 4 เครื่องมือ กลายเป็นการตัดสินใจเรื่องรายได้ ไม่ใช่แค่เรื่องคอนเทนต์

**ประมาณการ (ยังไม่ได้วัด):** ~3–5 pageview ต่อ 1 วง ถ้าหน้าจบทำงาน · ~1 ถ้าไม่ทำ

---

### 1. Sticky ล่างจอตลอดการเล่น — พร้อมข้อยกเว้นบังคับ

เจ้าของเว็บเลือก sticky หลังรับทราบความเสี่ยง invalid traffic แล้ว เดินตามนั้น **แต่ต้องกันจุดที่อันตรายจริง**

**ห้ามแสดง sticky บนสามจังหวะนี้เด็ดขาด:**

| จังหวะ | เหตุผล |
|---|---|
| หน้า **ส่งมือถือให้คนถัดไป** | มือเปลี่ยนคน นิ้วโดนจอโดยไม่ตั้งใจ — **นี่คือกลไกหลักของการกดโดน** |
| จังหวะ **เปิดเผยคำท้า / เฉลยผล** | สายตาทุกคนจับจ้อง แตะพลาดสูง และเป็นจังหวะที่โฆษณาทำลายเกมมากที่สุด |
| หน้า `ads:false` (สุ่มคนโดน) | ไม่มีโฆษณาเลยทั้งหน้า ตาม #09 |

เสียไป ~2 หน้าจอต่อรอบ แต่กันเหตุผลระงับบัญชีที่ **ไม่ใช่แค่เสียรายได้** — Google นับการกดโดนซ้ำ ๆ เป็น invalid traffic ซึ่งเป็นเหตุปิดบัญชี

**กฎการวางที่ต้องบังคับในโค้ด:**

1. **จองความสูงไว้ล่วงหน้าด้วย CSS** ห้ามให้โฆษณาโหลดแล้วดันเนื้อหา — layout shift ตอนโหลดคือ**กลไกอันดับหนึ่งของการกดโดนบนมือถือ** (ปุ่มเลื่อนลงตอนนิ้วกำลังลง) และมันตี CLS ซึ่งกระทบทั้งอันดับและรายได้ด้วย
2. **เว้นระยะจากปุ่มเกมที่ใกล้ที่สุดอย่างน้อย 1 ช่วงนิ้ว** ห้ามให้ปุ่มหลักกับช่องโฆษณาติดกัน
3. sticky อยู่นอก stage ของเกม ไม่ใช่ส่วนหนึ่งของ layout เกม เกมไม่ควรรู้ว่ามันมีอยู่

### 2. วางช่องเอง ไม่ใช้ Auto ads

**ผลพลอยได้ที่สำคัญ: การกันหน้า `ads:false` ลดจากสองชั้นเหลือชั้นเดียว** — ไม่มีสคริปต์ Auto ads ระดับเว็บมายัดโฆษณา ก็ไม่ต้องตั้ง page exclusion แค่ไม่เรนเดอร์ช่องบนหน้านั้น `GameLayout` จัดการจากฟิลด์ `ads` ของไฟล์เกมโดยตรง

และ Auto ads จะยัดโฆษณากลางเกมด้วย ML ซึ่งเป็นที่ที่แย่ที่สุดสำหรับ UI แบบนี้

### 3. ปิดหมวดโฆษณาแอลกอฮอล์ใน AdSense

ไม่เสียอะไรเลยเพราะ #01 ยืนยันว่า **ผู้ลงโฆษณาแอลกอฮอล์ target ประเทศไทยไม่ได้อยู่แล้ว** — ไม่มี demand ให้เสีย และกัน `/en/` ทีหลังไปในตัว

ที่สำคัญกว่า: มันปิดความขัดแย้งที่เว็บซึ่งอุตส่าห์ตัดคำว่าเหล้าออกทุกจุด กลับเสิร์ฟโฆษณาเบียร์เอง

### 4. หน้าจบเกมเสนอ 3 เกมถัดไป

อยู่ตรงจังหวะที่วงกำลังคิดว่า "เล่นอะไรต่อ" พอดี · เสนอเกมจริงพร้อมชื่อ ไม่ใช่ลิงก์ลอย ๆ ว่า "เกมอื่น"

**เกณฑ์การเลือก 3 เกม:** ไม่สุ่มมั่ว — เลือกจากเกมที่ **จำนวนผู้เล่นปัจจุบันเล่นได้** และ **ยังไม่ได้เล่นใน session นี้** ถ้าเสนอเกมที่เพิ่งเล่นจบไป ปุ่มจะตายทันที

**หน้า `ads:false` ต้องมีบล็อกนี้ด้วยและต้องเด่นกว่าหน้าอื่น** — มันคือหน้าที่หารายได้เองไม่ได้ หน้าที่เดียวของมันคือส่งคนต่อไปหน้าที่มีโฆษณา ถ้าเป็นหน้าตันคือรายได้ศูนย์เปล่า ๆ

### สิ่งที่ยังวัดไม่ได้จนกว่าจะมี traffic จริง

pageview ต่อ session · RPM จริงของตลาดไทย · sticky รบกวนจนคนเลิกเล่นไหม — **ทั้งสามข้อตอบด้วยการเดาไม่ได้** ต้องดู analytics หลังขึ้นจริง และเป็นเหตุผลที่ #05 เลือก Cloudflare Web Analytics ไว้แล้ว

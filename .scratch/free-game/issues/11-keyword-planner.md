# 11 — วัด long-tail ด้วย Google Keyword Planner

Type: task (HITL — ต้องมีบัญชี Google Ads)
Status: open
Blocked by: —

## Question

[#03](03-thai-seo-demand.md) ตอบเรื่องขนาดสัมพัทธ์ได้ดี แต่ทิ้งรูโหว่ที่ agent ชี้เองว่าเป็น **คำถามเดียวที่ยังค้างและกั้นการลงมือสร้าง**:

- Trends ให้ index 0–100 เทียบกันเอง **ไม่มีตัวเลข volume จริงเลยสักตัวในเอกสาร**
- Trends **วัด long-tail ไม่ได้** — และ long-tail คือทางเข้าเดียวที่เป็นไปได้ของเว็บที่ authority เป็นศูนย์ ในสนามที่หน้า 1 มีเจ้าถิ่น 8 ราย

แปลว่าตอนนี้เรารู้ว่า "คำไหนใหญ่กว่าคำไหน" แต่ไม่รู้ว่า **"คำที่เราพอสู้ไหวมีคนค้นเดือนละกี่ครั้ง"** ซึ่งเป็นตัวเลขที่ตัดสินว่าเว็บนี้คุ้มสร้างไหม

## Checklist (ประมาณ 20 นาที)

- [ ] เปิดบัญชี Google Ads (ไม่ต้องยิงโฆษณา ไม่ต้องจ่าย แต่บัญชีที่ไม่เคยใช้เงินจะเห็นเป็นช่วงกว้าง เช่น 1K–10K แทนตัวเลขเป๊ะ — รู้ไว้ก่อนจะได้ไม่ตกใจ)
- [ ] Keyword Planner → geo ไทย ภาษาไทย
- [ ] ดึง volume + competition ของ: `วงล้อสุ่ม` `สุ่มเลข` `สุ่มชื่อ` `วัดดวง` `เกมกลุ่ม` `เกมลงโทษ` `สุ่มคนโดน`
- [ ] **ที่สำคัญกว่า:** กด "ดูคีย์เวิร์ดที่เกี่ยวข้อง" ของแต่ละคำ แล้วเก็บ long-tail ที่ volume > 0 และ competition ต่ำ — นี่คือรายการที่เว็บใหม่พอมีสิทธิ์ติดจริง
- [ ] บันทึกลง `.scratch/free-game/research/keyword-planner.md`

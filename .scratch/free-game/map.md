# แผนที่: วัดดวง (watduang.com) — เว็บรวมเกมกลุ่ม

Label: `wayfinder:map`

## Destination

**Spec ที่พร้อมส่งให้ลงมือสร้างทันที** สำหรับเว็บ `วัดดวง / watduang.com` — เว็บรวมเกมกลุ่มเล่นฟรี 2-10 คน บนเครื่องเดียว ภาษาไทยก่อน หารายได้จาก Google AdSense

Spec ต้องตอบให้ครบว่า: **เกมอะไรบ้างใน v1 · โครงสร้าง URL/หน้าหมวดเพื่อ SEO · กลไกจำรายชื่อผู้เล่น · ตำแหน่งโฆษณา · tech stack + hosting · แผนคลังเนื้อหาไทย**

แผนที่นี้จบเมื่อไม่เหลืออะไรต้องตัดสินใจก่อนเขียนโค้ด — ไม่ใช่เมื่อเว็บเสร็จ

## Notes

**โดเมน:** `watduang.com` (whois ยืนยันว่าง 2026-08-13 · ยังไม่จด)

**แบรนด์:** ไทย = **วัดดวง** (`watduang.com`) — ตัดสินแล้ว · อังกฤษ = **PartyPick** (ปาร์ตี้พิค) — *เสนอ รอยืนยัน*

เวอร์ชันอังกฤษอยู่ที่ `watduang.com/en/` — **ไม่ซื้อโดเมนที่สอง** เพราะเว็บใหม่ที่ยังมี authority เป็นศูนย์ ไม่ควรหาร authority ออกเป็นสองก้อน และยังไม่มีหลักฐานว่าตลาดอังกฤษเอาด้วย

เหตุผลที่เลือก `PartyPick`: `pick` คือกลไกแกนกลางของทุกเกมในเว็บ (สุ่มว่าใครแพ้/ใครตอบ/ใครโดน) เกมที่เพิ่มทีหลังก็ยังอยู่ใต้ชื่อนี้ได้ · ทั้ง "ปาร์ตี้" และ "พิค" เป็นคำที่คนไทยใช้อยู่แล้ว · เลี่ยงคำกลุ่ม Lucky/Spin/Draw/Win โดยตั้งใจ เพราะมีกลิ่นพนันซึ่งเป็นหมวดที่ AdSense เข้มที่สุด

**หลักฐานโดเมน (เช็ค whois 78 ชื่อ 2026-08-13):** `.com` คำอังกฤษ 2 คำในหมวดนี้ถูกจดหมดแล้วทั้งหมวด — `partygame` `partypick` `grouppick` `randomparty` `playparty` `funparty` `drawlots` `notit` `temptfate` ตกหมด ว่างเหลือแค่ `thepartypick.com` `partyrandom.com` `wholoses.com` `wheelfate.com` ถ้าวันหนึ่งต้องการโดเมนอังกฤษแยกจริง ใช้ `thepartypick.com`

**เว็บอ้างอิง:** [PiliApp TH](https://th.piliapp.com/label/random/) — โครงคือ **1 เครื่องมือ = 1 URL = 1 คีย์เวิร์ด**, ไม่มี state ข้ามหน้า, ไม่มีบัญชีผู้ใช้, ads ต่อหน้า เขาโตด้วย SEO ไม่ใช่ virality

### ตัดสินไปแล้วจากรอบ grilling (ก่อนเปิดแผนที่)

- **เครื่องเดียว ส่งมือถือวนกัน** — ไม่มี backend, ไม่มี realtime, host เป็น static ได้ (multi-device คือเฟสถัดไป)
- **จำแค่รายชื่อผู้เล่นข้ามเกม** ผ่าน localStorage — ไม่มีสกอร์รวม ไม่มี session object
- **v1 มี 4-6 เกม** — พอไม่ให้ AdSense ตีว่า thin content
- **คลังเนื้อหา: AI ร่าง เจ้าของเว็บตรวจทุกข้อ**
- **ไทยก่อน อังกฤษทีหลัง**
- **ยังไม่มีโดเมน / ไม่มีบัญชี AdSense / ไม่เคยทำเว็บหาเงินจากโฆษณามาก่อน**
- เกมวัดดวง กับ เกมปาร์ตี้ **น้ำหนักเท่ากัน** ในหน้าบ้าน

### ข้อห้ามถาวร (ผู้ใช้กำหนดเอง — ห้าม ticket ไหนละเมิด)

เว็บนี้ **ไม่เกี่ยวกับแอลกอฮอล์** เราออกแบบเกมให้กลุ่มผู้เล่น จะดื่มหรือไม่ดื่มก็ได้ แปลว่า:

กฎชุดสุดท้าย หลัง [#01](issues/01-adsense-policy.md) · [#02](issues/02-thai-alcohol-law.md) · [#09 รอบสอง](issues/09-alcohol-in-metadata.md) ปิดครบ:

**🔴 ข้อที่ละเมิดไม่ได้เด็ดขาด**

1. **ห้ามภาพขวด กระป๋อง หรือแก้วที่มีโลโก้ ที่ไหนก็ตาม — รวม OG image และ thumbnail** ภาพเดียวพลิกทุกอย่างเข้ามาตรา 32/1 ทันที ตัวคำไม่ทำ แต่ภาพทำ · นี่คือกับดักจริงของหน้าเกมที่ต้องมีภาพสำหรับแชร์
2. **ห้ามคำท้าที่ชักจูงให้ทำร้ายร่างกายจริง** — ข้อเดียวในชุดนี้ที่เป็น *policy* ของ Google ไม่ใช่ *restriction* แปลว่าเสี่ยงถูกปิดบัญชีจริง
3. **ไม่มีชื่อยี่ห้อ ไม่มีลิงก์ร้าน ไม่มี affiliate แอลกอฮอล์** — ทุกมาตราที่เหลือของกฎหมายไทยต้องมีตัวเกาะพวกนี้ ตัดออกแล้วไม่มีอะไรเกาะ

**🟡 ข้อที่ทำได้ แต่มีเงื่อนไข**

4. **ชื่อกิจกรรม "ใครแพ้หมดแก้ว" ใช้ได้** — แต่หน้านั้นต้องตั้ง Auto ads *Page exclusion (This page only)* และไม่วางช่องโฆษณา manual · หน้านั้นจะไม่หารายได้เอง หน้าที่เดียวคือพาคนเข้าหน้าที่มีโฆษณา ห้ามเป็นหน้าตัน (ดู [#07](issues/07-ad-placement.md))
5. **เนื้อหาในเกมยังเป็นกลาง** — กติกา คำถาม คำท้า ไม่อ้างแอลกอฮอล์ บทลงโทษให้กลุ่มผู้เล่นตัดสินเอง
6. **คุมคำหยาบ** ไม่งั้นไปโดนข้อจำกัดคนละตัวชื่อ "Shocking content" · ห้ามโทนกราฟิกแบบเด็กกับเกมบทลงโทษสำหรับผู้ใหญ่

**⚪ ข้อที่พิสูจน์แล้วว่าไม่ต้องทำ**

7. **ไม่ต้องมี age gate** — ไม่มีผลทางกฎหมาย (ไม่มีมาตราไหนผูกกับอายุผู้ชม) Google ก็ไม่บังคับ และมันยัง**เป็นการยอมรับกลายๆ ว่าเนื้อหานี้เกี่ยวกับแอลกอฮอล์** เสียเปล่าทั้งสองทาง

### สโคปเนื้อหาที่ขยายแล้ว

เกมสนุก · เกมวัดดวง · **เกมวงล้อม** · เกมสันทนาการ · เกมเข้าค่าย · เกมกลุ่ม

**~~สมมติฐานเดิม: หมวดสันทนาการ/เข้าค่าย คือช่อง traffic ที่ใหญ่ที่สุด~~ — ตายแล้วจาก [#03](issues/03-thai-seo-demand.md) ผิดกลับด้าน ไม่ใช่แค่ผิดขนาด**

ตัวเลข Google Trends จริง (geo=TH, มี positive control): `เกมสันทนาการ` **เล็กกว่า** `เกมวงเหล้า` ~9 เท่า · `เกมเข้าค่าย` เล็กกว่า ~32 เท่า แบนที่ 0–1 มา 5 ปีโดยไม่มีฤดูกาลค่าย

**หน้าบ้านตัวจริงคือ `วงล้อสุ่ม`** — ใหญ่กว่าทุกหมวดเกมราว 21 เท่า และโต 10 เท่าตั้งแต่ปี 2021 รองลงมา `สุ่มเลข` (113) · `สุ่มชื่อ` (49) · `วัดดวง` (48) ส่วนหมวดเกมทั้งหมดรวมกันยังไม่ถึงเศษเสี้ยวของคำเดียวนั้น

กลุ่มครู/HR ที่สมมติฐานเดิมพูดถึง **มีจริงและใหญ่จริง แต่เข้ามาทาง `สุ่มชื่อ`/`สุ่มเลข` ไม่ใช่ `เกมสันทนาการ`** — ถูกกลุ่ม ผิดประตู

หมวดที่เดิมชื่อ `เกมวงเหล้า` **เปลี่ยนเป็น `เกมวงล้อม`** ตาม #09 — ตอนตั้งชื่อจริงใน #05 ให้ชั่ง `เกมล้อมวง` เทียบด้วย เพราะภาษาไทยพูดแบบนั้นเป็นธรรมชาติกว่า (`วงล้อม` แปลว่าการล้อมกรอบ)

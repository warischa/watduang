How the numbers were computed. Contrast: WCAG 2.x, relative luminance from sRGB channels linearised at the 0.03928 knee, ratio (L1 + 0.05) / (L2 + 0.05); the method first reproduced the Phase 0 figures #d6336c on #fff6e0 = 4.29, #ff3d7f on #fff6e0 = 3.13 and #ffcc00 on #ff3d7f = 2.23. Hero composites: source-over blend of the blob colour at its peak alpha onto #ff3d7f, then the same ratio. Mid frames: the easing curve's progress at half the duration, cubic-bezier solved numerically (ease-out 0.685, ease 0.802, ease-in-out 0.500, linear 0.500).

6 · Pick 6 · section reveal on scroll, below the first screen only

SELECTION PREDICATE, evaluated once at load: an element is a reveal target only if getBoundingClientRect().top > window.innerHeight. Anything whose top is on the first screen is never touched, so it cannot become a late LCP candidate (README D caveat). TARGET SET: main's sections and the tiles and cards inside them. NEVER: the ad slot (it must not move or fade), the hero, anything inside #stage. TRIGGER: IntersectionObserver, threshold 0, rootMargin "0px 0px -10% 0px" (fires when the element's top crosses 90% of the viewport height), once per element, then unobserved. NO-JS: no stylesheet rule hides anything; the pre-reveal class is added only by the script, so without JS every element is simply visible.

7 · Pick 2 · hero ambient gradient layer, motion half (the static look is the Gh288 home-hero board's)

COLOUR AND STRENGTH: see Gh288HomeHero (box, blobs, layer opacity and its contrast table live there). This sheet pins the motion only. Moved by transform only, the compositor path Phase 0 measured (raster 0, GPU-process 28ms per 3s vs 25 idle; the paint path was ~40x dearer and is out); scale is also compositor-only. RANGE CHECK against that board's travel limits (|tx| <= 27.27%, |ty| <= 22.22% of the layer box): this range is ±6% x and ±4% y, inside both; scale 1.08 is about the centre and only grows the layer, so it adds overhang and never brings an edge into the hero. OPACITY: the reduced form does NOT multiply by itself. A keyframe opacity replaces the element's opacity, so a literal 1 to 0.5 would override the hero board's 0.12 / 0.18 and paint the layer at full strength. The pinned reduced keyframes are therefore written relative to the board's value: opacity var(--glow) to calc(var(--glow) * 0.5), i.e. 0.18 to 0.09 or 0.12 to 0.06, never above the strength the board's contrast table approved. PHASE 3 NOTE: src/pages/index.astro sets animation: none !important on every element in main under reduced motion; that blanket rule would turn this reduced form into a removal, so the layer needs an exemption from it.

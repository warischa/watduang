# `siamsi` เป็นเกมที่แปด ไม่ได้แทน `daily-fortune`

#5 (ปิดแล้ว) เลือกแคตตาล็อก v1 ไว้ 7 เกม โดยมี `daily-fortune` (วัดดวงวันนี้ ~50 คำทำนาย) เป็นเกมวัดดวงหลัก แต่ `siamsi` (เซียมซีปาร์ตี้) ถูกสร้างและ ship ไปแล้วใน `aa5a251` โดยไม่มีใบและไม่อยู่ในเจ็ดนั้น — เพราะตอนตัดสินใจ เราไม่ได้อ่าน #5 และเข้าใจผิดว่าหมวด `fortune` ยังว่างอยู่

เราตัดสินว่า **แคตตาล็อกโตเป็น 8 เกม** เก็บทั้ง `siamsi` และ `daily-fortune` ไว้ โดยแยกกันด้วย **จำนวนคน**: `siamsi` คือเกมของวง (ส่งมือถือวนกัน คนละใบ) ส่วน `daily-fortune` คือของคนเดียว (เปิดดูเองทุกวัน)

## เหตุผล

ทั้งสองเกมจั่วคำทำนายเหมือนกัน ถ้าไม่แยกให้ชัดมันจะแย่ง keyword กันเอง ซึ่งเป็นสิ่งที่เว็บที่พึ่ง SEO ไม่ควรทำกับตัวเอง — แต่ "วงเล่นด้วยกัน" กับ "เปิดดูคนเดียว" เป็นคนละเจตนาการค้นหาจริงๆ ตามหลักเดียวกับ [ADR-0001](0001-category-means-search-intent.md) จึงยืนเป็นสองหน้าได้โดยไม่ทับกัน

## ผลที่ตามมา

การแยกนี้ไม่ได้ถูกบังคับด้วยโค้ดหรือ validator — มันอยู่ในการเขียน `seo.title` / `seo.description` / `keywords` ของทั้งสองเกมเท่านั้น ถ้าเขียนหลวมเมื่อไหร่ การแยกก็หายไปทันทีโดยไม่มีอะไรแตกให้เห็น ต้องคุมตอนเขียนเนื้อหา ไม่ใช่ตอนรีวิวโค้ด

`siamsi` จะมีโหมด "ใบหนึ่งคือคุณโดน" อยู่ข้างในเกมเดิม (ไม่แตกเป็น URL ใหม่) ซึ่งทำให้มันเป็นทั้งเกมวัดดวงและเกมหาคนโดนในกลไกเดียว ตรงกับแกน **ดวงตัดสิน** ใน `CONTEXT.md`

# เกณฑ์ตัดสินอนาคตเว็บคือ organic clicks จริง ไม่ใช่ตัวเลขคาดการณ์

#12 ตั้งไว้ว่าเกม 2–7 และคลังเนื้อหา ~230 ข้อจะถูก pause จนกว่า Google Keyword Planner จะตอบว่า "โมเดล AdSense คุ้มไหม" โดยมีช่องว่าง "ต่ำกว่า `_____` ครั้ง/เดือน" ให้เติมก่อนเปิดเครื่องมือ — **ช่องนั้นไม่เคยถูกเติม และไฟล์ worksheet ไม่เคยถูกสร้าง** gate จึงบล็อกงานอยู่โดยไม่มีเลขให้ผ่านหรือไม่ผ่านมาตลอด

เกณฑ์ใหม่: **organic clicks จาก Google Search Console ต่ำกว่า 300 ครั้ง/เดือน ที่เดือนที่ 6 = SEO ไม่ทำงาน** โดยเดือนที่ 1 เริ่มนับตอนที่ `/tools/` ตัวแรกและเกมครบ 3 เกมขึ้น production แล้ว

## เหตุผล

Keyword Planner บอก demand ของ *คำค้น* แต่คำถามจริงคือ *เว็บนี้จะได้ส่วนแบ่งไหม* ซึ่งเป็นคนละเรื่องและเครื่องมือคาดการณ์ตอบไม่ได้ — โดยเฉพาะกับโดเมนใหม่ที่โดนหักอันดับ 6–12 เดือนแรก การวัด clicks จริงวัดผลลัพธ์ปลายทางโดยตรง ไม่ต้องตีความ และเครื่องมือฟรีมีอยู่แล้ว

เลข 300 ไม่ได้แปลว่าคุ้ม — ที่ ~2 pageview ต่อ click และ RPM ไทยแบบ NPA มันคือรายได้เดือนละไม่กี่สิบบาท **มันวัดว่ามีคนหาเจอหรือเปล่าเท่านั้น** ซึ่งเป็นคำถามเดียวที่เดือน 6 ตอบได้อย่างซื่อสัตย์ คำถามเรื่องกำไรต้องรออีกหลายเท่า

จุดเริ่มนับถูกเลือกให้อยู่ที่ "tool + 3 เกม" ไม่ใช่ "วัน deploy" และไม่ใช่ "ครบ 8 เกม" เพราะทดสอบตอนมี 2 เกมคือทดสอบปริมาณเนื้อหาของเราเอง ไม่ใช่ทดสอบ demand ส่วนการรอให้ครบ 8 เกมแปลว่าต้องจ่ายค่าเนื้อหา ~230 ข้อไปทั้งหมดก่อนถึงจะได้รู้ผล ซึ่งทำให้ gate ไม่มีความหมาย

## ถ้าไม่ถึงเกณฑ์

เขียนไว้ล่วงหน้าก่อนจ่าย: **เปลี่ยนตลาด — ดัน `/en/` PartyPick เป็นหลัก** ไม่ใช่เลิกทำและไม่ใช่เปลี่ยนช่องทางหา traffic

ผลที่ตามมาซึ่งมีผลกับลำดับงานตั้งแต่วันนี้: เนื้อหาภาษาไทย ~230 ข้อคือของที่ถูกทิ้งตอน pivot ส่วนกลไกของเกมคือของที่ติดตัวไป — **เกมที่ไม่มีคลังเนื้อหาจึงมีความเสี่ยงต่ำกว่าเกมที่ต้องเขียน 80–100 ประโยคอย่างมีนัย** และเป็นเหตุผลหนึ่งที่ `pick-loser` (0 ข้อ) ถูกเลือกเป็นเกมที่ 3

## #12

ไม่ถูกปิด — เหลือเป็นงาน keyword research ล้วนๆ ซึ่งยังมีค่าสำหรับเลือกคำลง `seo.title` / `seo.description` / `keywords` ของเกมที่มีอยู่ ส่วน gate ย้ายไปอยู่ใบใหม่ที่อ้าง ADR นี้ ต้องแก้ข้อความใน #12 ให้เลิกอ้างว่าตัวเองเป็น gate

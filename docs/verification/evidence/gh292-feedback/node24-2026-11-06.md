## Cold-start finding

The first request after idle, and the first request after a restart, returned 500 and wrote no row (n=3, on both
Node versions). A warm repeat of the same request returned 303. A visitor who is first after idle loses the message
and sees an error, not `/feedback/failed/`. This is not caused by the Node change. It is recorded for its own ticket.

## Findings

### PD-306-01 · major · cards 3D field above 102 names · 1920 (projector width)
- Rule: `readable-font-size`, and legibility at projector distance (the board's own floor).
- Evidence: `game-prize-cards-play-1920-reveal-02-start.png` (200 names, deal).
  - Card digits paint **9px** tall. The 20px 2D chip at the same scale paints 14px
    (`game-prize-fireworks-play-1920-idle.png`), so the name renders at about 13px on screen.
  - The code agrees. `fieldLayout` keeps the board's 293x40 card and scales the whole field by one factor;
    for 200 cards it picks 8 columns at s ≈ 0.693.
  - That gives `NAME_FIT` 20px × 0.693 ≈ 13.9 frame px (13.1 screen px at 0.948). The floor (16 card
    units) becomes 11.1 frame px.
- Board: Gh303Cards VALUES says "names have an 18px floor (16px on cards) … because lanterns and cards are
  read from further back". Its field is drawn for 100 cards on 6 columns. The code comment says the board
  draws no layout above that.
  - The build matches the board up to 102 cards.
  - Above 102 cards the board says nothing, and the floor is broken.
  - 200 is the head-count ceiling.
- Disposition: **owner-pick**.
  - (a) Hold 16px in frame px. The card narrows above 102: a smaller rank column, the name box kept at
    16px. This needs a board frame for 200.
  - (b) Accept about 14px above 100 cards, and stamp it on the board as the >100 rule.
  - (c) Above N names (owner sets N), the round reveals on the 2D chips (20px), with the rank and suit as a
    tag on each chip.

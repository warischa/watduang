Screen audited: `/game/prize-draw/join/` at 320 and 375, in its one rendered state: an unknown event (the

**The QR on the main screen is not built yet**, so the projector side of QR join (the code, and the admin's

## Findings

### PD-308-01 · major · join, name screen submit · 320 and 375 (read from source, not rendered)
- Rule: `loading-buttons`, `submit-feedback`, `tap-feedback-speed`.
- Evidence (source):
  - `submitName` sets the join button `disabled` and the field `readOnly` while the request runs. A send
    may take up to `SEND_TIMEOUT_MS` = 15000 ms before it is retried.
  - The page's only rule for that state is `.pj-btn:disabled { cursor: progress; }`. A phone shows no
    cursor, so the button looks exactly as before for up to 15 s, with no spinner and no label change.
  - The likely result is repeated taps and a guest who thinks the page froze.
- Board: Gh302Phone A says the reveal pages have no loading state, because they make no server call. The
  join send does make one, and the board draws no busy state for it.
- Disposition: **owner-pick**.
  - (a) The projector MC button's disabled look: opacity 0.55, as `.pd-go:disabled` (named in
    Gh305GamePick VALUES).
  - (b) A label swap while sending (`[copy: owner]`).
  - (c) Both.

### PD-308-02 · minor · join, event not found · 320 and 375
- Rule: `error-recovery`, `error-clarity`.
- Evidence: `game-prize-draw-join-320-join.png` and `game-prize-draw-join-375-join.png`.
  - The answer "ไม่พบงานนี้ ลองสแกน QR บนจออีกครั้ง" is the page heading (Mitr 700, ink on cream).
  - Under it is an empty cream screen, and the 48px ink header band holds nothing.
  - The recovery is physical (rescan), which the copy names. But there is no error marker and no control.
    The board's error rows elsewhere on this page (`.pj-emsg`) use a punch disc icon and bold text.
- Board: not drawn. The page's own copy table says these answers are owner-approved copy the board does
  not draw.
- Disposition: **owner-pick**.
  - (a) Keep it.
  - (b) The board's error row (punch disc icon, bold 16px) under a neutral heading.
  - (c) Add a retry button that reloads the page (`[copy: owner]`).
